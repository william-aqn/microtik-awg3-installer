Mode button

One press: connect or disconnect. Two presses within 1.5 seconds: stop the container.
USR flashes twice to acknowledge the stop command. Press Mode once to start again.

Disconnect keeps this panel available. Stopping the container also closes the panel. USR lights when the tunnel has a recent handshake; diagnostics show the exact time.
