# Работа с AWG Control

[Установка и кнопки](../README.md) · [Подготовка и устранение проблем](../GOTCHAS.md)

Панель открывается из LAN по `http://<LAN-IP-роутера>:8088`. Это отдельная страница управления VPN.

![Панель AWG Control с демонстрационным профилем](../docs/media/awg-profiles-preview.png)

На скриншоте вымышленные данные; настоящие адреса и ключи в репозиторий не включены.

## Профили

1. Открой **VPN profiles → Import profile**.
2. Выбери нативный `.conf` AmneziaWG или вставь его текст, задай имя и нажми **Save profile**.
3. Нажми **Connect** на нужной карточке.

Можно хранить несколько профилей и переключаться между ними; активен один. Сохранение профиля не прерывает соединение.

**Edit** открывает полный конфиг и поля сервера, DNS, MTU. После сохранения нажми **Apply saved profile**, чтобы применить изменения к соединению. **Export** скачивает конфиг. **Reconnect** переподключает текущий профиль, **Restore previous** возвращает снимок предыдущего подключения. При неудачной активации контроллер пытается восстановить рабочий профиль автоматически.

**Disconnect** выключает VPN и оставляет панель доступной. **Stop container** останавливает и VPN, и панель; включить их можно кнопкой Mode у USB.

## Устройства и маршруты

В **Devices** выбери общий режим и, при необходимости, исключения для отдельных устройств, затем примени настройки.

| Режим | Куда идёт интернет при подключённом VPN |
|---|---|
| **Direct** | Через обычный WAN |
| **Geo** | Выбранные сайты и IP через AWG, остальное напрямую |
| **VPN** | Весь IPv4-интернет через AWG |
| **Default** | По общему режиму |

Общий режим по умолчанию — **VPN**. Локальные сети доступны напрямую. Явное отключение соединения или остановка контейнера возвращает устройствам обычный интернет.

## Geo-списки

В **Geo lists** выбери категории IP/доменов и источники, загрузи списки и примени их. Доступны [Loyalsoldier/geoip](https://github.com/Loyalsoldier/geoip), [v2fly/domain-list-community](https://github.com/v2fly/domain-list-community) и [Antifilter](https://antifilter.download/).

Для загрузки списков VPN должен быть подключён. Для доменных правил устройствам нужен DNS MikroTik. Подробности DNS и лимиты памяти — в [GOTCHAS.md](../GOTCHAS.md#dns-и-geo).

## Проверка состояния

На главной видны состояние соединения, время последнего handshake, RX/TX и свободная память. **Diagnostics** показывает подробности. После подключения проверь внешний IP и открытие сайтов на устройстве за MikroTik.

Для физического управления используй [кнопки роутера](../README.md#кнопки).
